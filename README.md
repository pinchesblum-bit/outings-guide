# Outings Guide

Category-based family outings website.

## Preview
https://outing-guide.pinchesblum.chatgpt.site

## Files
- index.html: main page
- style.css: responsive styling
- app.js: categories, sample outings, search, and detail views
- park.jpg: category image

Open index.html in a browser. No installation or build is required. All categories and listings are clearly labeled samples, pending import of the actual booklet.
